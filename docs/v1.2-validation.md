## Playback

At 1× playback:

- The first displayed token waits for simulated TTFT.
- Every later token waits for its corresponding TPOT.
- AFM Token 33 includes the IFP selection, delta NAND read and patch delay.
- The output window inserts an `IFP Window` marker at each boundary.

## Limitations

This validation confirms internal consistency, not correspondence to Apple hardware measurements. Selector, patch, common-resident weight and compute inputs remain calibration parameters.
