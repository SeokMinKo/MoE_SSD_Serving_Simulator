## V1.5 invariants covered by regression tests

- cache byte capacity includes packing overhead
- safe integer parsing and fail-closed validation of all calculation fields
- threshold order and relational constraints are rejected rather than normalized
- invalid render clears stale KPI, tables, charts and playback state
- swap-out source residency remains until write completion
- swap-in waits reap completed pending page-outs before new pressure accounting
- AFM pipelined overlap requires double buffering
- previous-token prefetch has no first-token future-route oracle
- evicted prefetch entries cannot later be counted as useful
- stable same-time event ordering
- shared SSD/DRAM/PCIe/compute resource contention
- single-request Colibri and AFM timelines preserve the analytic no-contention baseline
- swap I/O is included in scheduler SSD work
- AFM selector/initial patch/prefill are included in scheduler TTFT
- data-ready requests inside the admission window batch together
- malformed requests and oversized scenario artifacts are rejected
- import Run ID must match canonical config and request shape
- deterministic import replay must reproduce every persisted numeric metric, OOM status and model-status value
- concurrent auto placement reserves KV capacity using the full request count
- empty required numeric controls are rejected rather than coerced to zero
- 30-scenario finite/resource-bound property matrix

## Explicit trust boundary

V1.5 does **not** validate or support claims about:

- absolute TTFT, TPOT, TPS, SLA, tail latency or capacity planning
- hardware purchase comparisons
- kernel-level GPU continuous batching
- request fairness or production scheduler semantics
- cross-request Expert-cache residency sharing
- in-flight Expert-read coalescing
- GPU VRAM bandwidth, page migration or kernel launch/graph behavior
- OS page-level VM behavior
- an empirical SSD QD/read-size service curve

SSD QD currently affects command-latency waves under one aggregate bandwidth cap; it is not a model of actual outstanding slots. Real runtime traces, device service-curve calibration and hold-out validation are required before using absolute metrics.

Scenario replay and the UI self-test execute the same JavaScript model and are regression checks, not independent physical oracles.
